
# Student Profiling Runner (RCA)

This file contains the end-to-end runner for generating a **StudentInteractionProfile** JSON object from an **RCLog** input.

The runner orchestrates the full pipeline:

1. Load RCLog JSON
2. Convert RCLog to `turns` (chat-style messages)
3. Run rule-based prompt type classification
4. Compute indicator metrics + evidence snippets (CT / PS / ENG)
5. Compute scores (CT / PS / ENG)
6. Classify overall AI use pattern
7. Generate a short natural-language summary (`process_notes`)
8. Assemble everything into a single schema-compliant output JSON
9. Write output JSON into `output/sample_profiles/` for testing

## Input Format

### RCLog (required)
All inputs are expected to be in **rclog format** (JSON file). The runner will:
- load the rclog file
- convert it into unified chat `turns` using:
  - `tools/rclog_to_turns.py`

### Turns (derived)
After conversion, the runner expects `turns` to look like:

```json
{
  "role": "student",
  "text": "message text here",
  "timestamp": "2025-12-04T10:30:00Z"
}
```

---

## Output Format

The runner produces one **StudentInteractionProfile** JSON file per input, matching:

* `schema/output_schema.json`

The output includes:

* `submission_id`
* `profile_generated_at`
* `scores` (CT / PS / ENG)
* `ai_use_pattern`
* `process_notes`
* `indicator_metrics` (raw metrics + prompt type distribution)
* `explainability_evidence` (evidence snippets + confidence per dimension and pattern)

Outputs are written to:

* `revision_chain_analysis/student_profiling/output/sample_profiles/<submission_id>.json`

## How to Run

###  Run from Python (recommended for dev/testing)

From repo root:

```bash
 python -c "import sys; from pathlib import Path; sys.path.insert(0, str(Path('.').resolve())); from revision_chain_analysis.student_profiling.tools.profile_runner import run_student_profiling_from_rclog; run_student_profiling_from_rclog(rclog_path='revision_chain_analysis/student_profiling/test_files/rclog_MFA_example.json')"
```

This will:

* generate the profile
* write the JSON output into `output/sample_profiles/`
* validate the output against the schema (if `jsonschema` is installed)

---

## Schema Validation

Schema validation uses the optional dependency:

* `jsonschema`

If installed, the runner will validate the final profile against:

* `revision_chain_analysis/student_profiling/schema/output_schema.json`

Install it:

```bash
pip install jsonschema
```

If `jsonschema` is not installed, validation is skipped and a warning is printed.

## Pipeline Dependencies (Internal Modules)

The runner depends on these modules:

### 1. RCLog to Turns

* `revision_chain_analysis/student_profiling/tools/rclog_to_turns.py`

  * `load_rclog(path)`
  * `rclog_to_turns(rclog_json)`

### 2. Prompt Type Classification

* `revision_chain_analysis/student_profiling/prompt_classifier/prompt_classifier.py`

  * `run_prompt_type_classification(turns)`
  * returns:

    * `classified_turns`
    * `prompt_type_distribution` (counts)

### 3. Indicators + Evidence

* `indicators/critical_thinking.py`

  * `compute_ct_indicators_and_evidence(turns)`
* `indicators/problem_solving.py`

  * `compute_PS_indicators_and_evidence(turns, classified_turns)`
* `indicators/engagement.py`

  * `compute_engagement_indicators_and_evidence(turns, classified_turns)`

### 4. Scoring Engine

* `scoring/scoring_engine.py`

  * `score_critical_thinking(ct_counts)`
  * `score_problem_solving(ps_counts)`
  * `score_engagement(eng_metrics)`

### 5. AI Use Pattern Classifier

* `patterns/pattern_classifier.py`

  * `classify_ai_use_pattern(prompt_distribution_proportions, ps_indicators, ct_indicators)`
  * returns one of:

    * `generator_only`
    * `reviser`
    * `planner_checker`
    * `mixed`

### 6. Summary Generator

* `summary/summary_generator.py`

  * `build_process_notes(pattern: str, scores: dict) -> str`

### 7. Profile Builder

* `output/profile_builder.py`

  * `build_student_interaction_profile(...)`
  * `save_profile_json(profile, output_dir, filename_stem)`
  * `validate_profile_against_schema(profile, schema_path)`
